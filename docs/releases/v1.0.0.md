# Release Notes — v1.0.0

**Date** : 2026-08-02  
**Tag** : `v1.0.0`  
**Produit** : BotoSchool Email Platform

---

## Résumé

Première version production-ready de la plateforme de prospection email BotoSchool :
campagnes avec validation obligatoire, workers BullMQ, gates CDC (`DRY_RUN` /
`PRODUCTION_SENDING_ENABLED`), multi-ESP SMTP, DNS, monitoring, staging et rampe
de volume contrôlée.

---

## Contenu principal

### Métier
- Contacts, organisations, imports CSV/XLSX, segments
- Templates, séquences (3 étapes CDC), campagnes (workflow validation → envoi)
- Réponses, tâches commerciales, liste de suppression
- Désinscription tokenisée
- Conformité CNDP (DSR, anonymisation, rétention)

### Technique
- Next.js 16 · Prisma 7 · PostgreSQL · Redis/BullMQ · Auth.js RBAC
- Presets SMTP : Brevo, Mailgun, SES, SendGrid, Postmark
- Health live/ready · `/ops/*` · métriques Prometheus · Grafana (profile)
- Docker prod / staging · backups · CI/CD

### Sécurité & ops
- Headers / CSP / CSRF · rate-limits · secrets Docker
- Rampe **10 → 50 → 100 → 500 → 1000 → progressif**
- Kill switch documenté

---

## Prérequis avant envoi réel

1. Checklist prod signée — `docs/production/00-CHECKLIST.md`
2. Staging smoke — `npm run smoke:staging`
3. DNS GO — `npm run dns:checklist` + `/ops/dns`
4. SMTP GO — `npm run smtp:checklist` + `/ops/smtp`
5. Rampe R0 — `npm run ramp:checklist`

**Défaut sûr** : `DRY_RUN=true`, `PRODUCTION_SENDING_ENABLED=false`.
